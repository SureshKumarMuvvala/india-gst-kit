# Error-code lists (`sources/errors/`)

Captured on **2026-10-18** through a browser in India. No login or CAPTCHA was needed.

**How the files were made.** Each page's single `<table>` was read row by row in the browser; every cell is the cell's `textContent` with U+00A0 replaced by a space, whitespace runs collapsed to one space, and trimmed. The rows, header row included, were written as one compact JSON array of arrays (`JSON.stringify`, no spaces). The SHA-256 of that string was computed in the browser and matched against the committed file (`SHA256SUMS`). Text, including the portals' spelling mistakes, is unchanged.

## Findings

- **X1. Codes repeat across the e-invoice lists.** 3029, 3074–3079 and 5001 are in both VITAL and INV, and 4001 is in both INV and EWB, sometimes with different wording. A lookup must be keyed by list (system and API group) as well as code, or must pick one wording.
- **X2. e-invoice and e-way bill code spaces are different systems.** e-way bill API codes (100–865) and e-invoice codes (1004–9999, `_3109`) overlap numerically only by accident; never look one up in the other's list.
- **X3. One odd code:** VITAL lists `_3109` (leading underscore) with the same message as 3108.
- **X4. Token/session codes** for the `gsp` package's `authErrorCodes` (spec V11): e-invoice 1005 "Invalid Token"; e-way bill 105 "Invalid Token", 106 "Token Expired", 238 "Invalid auth token". Still to be confirmed on a live call.
- **X5. Duplicate-request codes:** e-invoice 2150 "Duplicate IRN", 2295 (IRN already generated by another IRP), 2278 (IRN generated and cancelled for this number), and e-way bill 604 / IRP 4026 (e-way bill already exists for the document). These are the "already done" cases where a client should fetch, not retry.
- **X6. Throttling / blocking codes:** e-invoice 3095, 3096, 3108; e-way bill 118 "Try after 5 minutes", 658, 813.
- **X7. Message 2240's resolution names "Standard tax Rates are 0, 0.5, 1, 2, 3, 5, 12, 18, 28".** This is not a rate list and must not be used as one (it conflicts with "Tax rate 0.5% is withdrawn" in the validations and with later rate changes).
- **X8. Placeholders** such as `{0}`, `{1}` appear in messages; one is malformed (IRP EWB 4074: `{0)`).
